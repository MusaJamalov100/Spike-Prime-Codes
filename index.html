PID Line Follower for LEGO SPIKE Prime

Python code that keeps a SPIKE Prime robot on a black line, smoothly and accurately. Pick the 1-sensor or the 2-sensor version below and copy it into the SPIKE App.

Choose a version

VersionSensorsBest for
1 sensor1 Color Sensor on port ASimple builds. Follows the edge of the line.
2 sensorsColor Sensors on ports A and BMore stable tracking. Needs no target value.

Code

The sensor follows the edge of the line, so it should see half black and half white. Motors are on ports C and D.

from hub import port
import motor_pair, color_sensor, runloop

motor_pair.pair(motor_pair.PAIR_1, port.C, port.D)

# Follow the right side of the black line (Black-White edge).
# To follow the other edge, use: error = reflection - 50

TARGET = 50
KP = 0.5
KI = 0.001
KD = 1
SPEED = 300


async def pid_line_follow_forever():
    integral = 0
    last_error = 0

    while True:
        error = TARGET - color_sensor.reflection(port.A)

        # keep the integral small so it does not grow too much
        integral = max(-3000, min(3000, integral + error))
        derivative = error - last_error
        last_error = error

        correction = int(KP * error + KI * integral + KD * derivative)
        correction = max(-100, min(100, correction))

        motor_pair.move(motor_pair.PAIR_1, correction, velocity=SPEED)

        # small pause so every loop takes the same time
        await runloop.sleep_ms(10)


async def main():
    await pid_line_follow_forever()

runloop.run(main())

Put the line between the two sensors. When the line is centered, both read the same value and the error is zero. If the robot turns the wrong way, change the error line to error = left - right.

from hub import port
import motor_pair, color_sensor, runloop

motor_pair.pair(motor_pair.PAIR_1, port.C, port.D)

# Two sensors: A = left sensor, B = right sensor.
# Put the line BETWEEN the two sensors.
# If the robot turns the wrong way, change the error line to:
# error = left - right

KP = 0.4
KI = 0.0005
KD = 1
SPEED = 300


async def pid_line_follow_forever():
    integral = 0
    last_error = 0

    while True:
        left = color_sensor.reflection(port.A)
        right = color_sensor.reflection(port.B)

        # when the line is in the middle, both sensors read the same
        # and the error is 0
        error = right - left

        # keep the integral small so it does not grow too much
        integral = max(-3000, min(3000, integral + error))
        derivative = error - last_error
        last_error = error

        correction = int(KP * error + KI * integral + KD * derivative)
        correction = max(-100, min(100, correction))

        motor_pair.move(motor_pair.PAIR_1, correction, velocity=SPEED)

        # small pause so every loop takes the same time
        await runloop.sleep_ms(10)


async def main():
    await pid_line_follow_forever()

runloop.run(main())

How it works

Every 10 milliseconds the program measures how far the robot is from the line (the error) and turns the motors to correct it:

correction = Kp * error + Ki * integral + Kd * derivative

The correction is used as the steering value of the motor pair, limited to -100...100.

Calibration (1-sensor version)

  1. Place the sensor on white and note the value, for example 90.
  2. Place the sensor on the black line and note the value, for example 10.
  3. Set TARGET to the middle: (90 + 10) / 2 = 50.

PID tuning

  1. Set KI and KD to 0. Raise KP until the robot starts to oscillate.
  2. Raise KD to reduce the oscillation.
  3. If needed, add a very small KI.
ConstantRoleIf too high
KPReacts directly to the errorRobot oscillates
KICorrects accumulated errorRobot becomes unstable
KDReacts to how fast the error changesRobot jitters

Troubleshooting

  • Robot loses the line: lower SPEED or raise KP.
  • Robot oscillates too much: lower KP and raise KD.
  • Robot turns the wrong way: flip the sign of the error or check the motor ports.
  • Readings are unstable: check the sensor height above the floor and reduce room light.
